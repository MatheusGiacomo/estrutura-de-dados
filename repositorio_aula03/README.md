## Como usar

Clone o repositório uma única vez:

```bash
git clone <url-do-repositorio>
cd <pasta-do-repositorio>
```

Antes de cada aula, atualize para receber os arquivos novos:

```bash
git pull
```

Entre na pasta da aula, abra os arquivos e resolva os exercícios seguindo os
comentários.

## Compilação

Os exercícios usam apenas a biblioteca padrão e compilam com `g++`:

```bash
g++ arquivo.cpp -o programa
./programa
```

## Resoluções

Cada aula tem sua resolução na branch `gabarito`, liberada após o encontro.

```bash
git fetch origin
git checkout gabarito
```

Para voltar aos exercícios sem resposta:

```bash
git checkout main
```
